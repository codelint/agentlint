碼靈（Codelint）隱私權政策

生效日期：2026-10-20


一、概述

碼靈（Codelint）是一款執行在 iPhone 與 iPad 上的 AI 程式開發助理用戶端。它的定位是
「工具」：由你提供模型服務位址、工作區檔案與目標主機，碼靈在你指定的範圍內代為
執行操作。

碼靈提供兩種使用方式：

1. 自行設定模型服務：你填寫自己的大模型 API 位址與金鑰，對話直接由你的裝置傳送到
   該位址，不經過我們；
2. 使用內建模型：登入帳號後，你可以使用我們提供的內建模型額度，此時對話內容會經
   我們的伺服器轉發給模型服務供應商。

為提供帳號、訂閱額度與內建模型，碼靈設有一套由開發者營運的伺服器（
https://ios.codelint.com）。除下文明確列出的內容外，我們不會蒐集、儲存或上傳你的
檔案、程式碼與對話內容。


二、我們蒐集的資訊

1. 帳號資訊（登入時蒐集）

   登入是可選的：不登入也可以使用自行設定模型的全部能力。

   - Apple 登入：我們會收到 Apple 提供的使用者識別碼（sub）。若你授權，還會收到你的
     電子郵件（可能是 Apple 的私密轉寄位址）與姓名。
   - 電子郵件驗證碼登入：我們會收到你填寫的電子郵件，並向該信箱傳送一次性驗證碼。

2. 登入憑證與登入裝置

   - 登入成功後，伺服器簽發存取憑證（secret），僅保存在你裝置的安全儲存（Keychain）
     中。
   - 為顯示與管理登入裝置，伺服器會記錄用戶端產生的裝置識別碼（duid）、最近一次
     登入時間與來源 IP 位址。

3. 訂閱與購買

   訂閱透過 Apple App Store 內購完成。我們不會接觸你的付款方式、卡號或帳單位址；
   僅從 Apple 收到交易憑證，用於校驗訂閱檔位與到期時間，並在伺服器記錄你的檔位與
   額度。

4. 內建模型呼叫（登入並使用內建額度時）

   當你使用內建模型時，對話內容、工具呼叫參數與工具結果會經我們的伺服器轉發給模型
   服務供應商。伺服器只統計用量資訊並用於額度扣減，包括：模型名稱、上游網域、請求
   ID、請求位元組數、token 用量、回應狀態與耗時。

   伺服器不保存對話內容、程式碼內容與工具結果內容。

5. 意見回饋（你主動提交時）

   當你在 App 內提交回饋時，會上傳：標題、內容、你選擇填寫的聯絡方式，以及用戶端
   環境資訊（應用程式版本與建置號、系統版本、機型、語言與地區、時區、可用儲存空間、
   目前角色名稱）。環境資訊用於定位問題，不含你的工作區內容與對話內容。

6. 用量與額度

   伺服器按帳號記錄內建模型的呼叫次數與 token 用量，用於額度結算與顯示。

7. 我們不做的事

   - 不使用廣告識別碼（IDFA），不做跨 App 追蹤
   - 不接入第三方廣告或第三方統計分析 SDK
   - 不蒐集通訊錄、通話紀錄、簡訊
   - 不在背景下持續取得你的位置
   - 不出售、出租你的個人資訊


三、你自行設定的服務

以下資料的去向完全由你決定，我們不參與也不留存：

1. 模型服務
   你在設定中填寫的大模型 API 位址與金鑰。當你發起對話或呼叫工具時，對話內容、程式碼
   片段與工具輸出會傳送到你指定的位址，其處理方式取決於該服務供應商的政策。
   為便於模型服務供應商排查呼叫問題，請求標頭會附帶應用程式名稱與版本號、系統版本、
   裝置型號與系統地區設定（User-Agent），不含帳號、IP、裝置唯一識別碼或對話內容。

2. SSH 主機
   你新增的遠端主機位址、連接埠、使用者名稱與金鑰，僅用於連線你自己的主機，
   並儲存在本機。

3. MCP 服務
   你新增的 MCP 服務端點，請求僅傳送至你設定的位址（可為區域網路或遠端位址）。

4. 可選的本機代理元件
   專案原始碼中附帶一個可自行部署的介面代理元件，用於轉發與統計模型呼叫。若你自行
   部署並將模型請求指向它，流量將經過你自己的伺服器；我們不提供該元件的託管服務。


四、儲存於本機的資料

以下內容保存在你的裝置本機（SwiftData 與 App 沙盒內）：

- 工作區檔案與目錄，以及檔案修改紀錄
- 工作階段與對話紀錄、技能與提示詞
- 模型服務位址與金鑰、SSH 主機設定、MCP 服務設定
- 登入憑證（僅 Keychain）
- App 執行日誌與事件紀錄（僅用於本機問題排查）

清除方式：在 App 內刪除對應項目即可移除；解除安裝 App 會一併清除全部本機資料。


五、裝置權限及用途

碼靈僅在下列用途申請系統權限，且均可在系統設定中拒絕：

- 區域網路：連線同一區域網路內的 MCP 服務
- 相簿（僅寫入）：將工作區中的圖片儲存到你的相簿
- 媒體資料庫：搜尋並播放你「音樂」App 中的歌曲
- 麥克風與語音辨識：把你說的話轉成文字填入輸入框
- 定位（使用期間）：僅在你主動詢問需要位置脈絡的問題（例如「我附近的網路環境」
  「目前位置」「附近的咖啡館」等）時，才會暫時取得你的大略位置，作為傳送給 AI 的
  對話脈絡，並用於顯示目前連線的 Wi-Fi 名稱；不會在背景持續追蹤位置
- 通知：於本機提醒任務執行結果（不經過任何伺服器推播）
- 剪貼簿：僅在你主動點擊介面中的「複製」按鈕時才會寫入系統剪貼簿；本 App 不提供
  AI 自動讀取剪貼簿的工具，不會未經你確認就讀取剪貼簿內容

拒絕某項權限只會影響對應功能，不影響其餘功能的使用。


六、資料分享與第三方

我們只在必要時與下列第三方分享資料：

- Apple：Apple 登入（驗證身分）、App 內購買（校驗訂閱），受 Apple 隱私權政策約束
- 模型服務供應商：僅在你使用內建模型時，由我們的伺服器轉發你的請求內容
- 郵件服務供應商：向你的信箱傳送登入驗證碼與回饋回執

除上述情形及法律要求外，我們不會向第三方提供你的資料。


七、資料保留與刪除

- 本機資料：你隨時可在 App 內刪除對話、檔案或設定；解除安裝 App 即刪除全部本機資料。
- 帳號資料（電子郵件、Apple 使用者識別碼、訂閱檔位、額度與用量、登入裝置紀錄）：於
  帳號存續期間保留。你可寄送郵件至 codelint@foxmail.com 申請刪除帳號，我們將於 15 個
  工作日內刪除或匿名化處理，法律法規要求保留者除外。
- 伺服器不保存對話內容，因此不存在需要單獨刪除的對話內容副本。


八、資料安全

- 用戶端與伺服器之間的通訊使用 HTTPS（TLS）加密；
- 登入憑證保存在系統 Keychain，模型金鑰與 SSH 金鑰依你的選擇保存在 Keychain 或本機
  沙盒；
- 伺服器對帳號資料按最小必要原則儲存，存取受權限控制。


九、兒童隱私

碼靈面向具備程式開發能力的開發者，並非面向 16 歲以下未成年人，也不會在知情的情況下
蒐集未成年人的個人資訊。若你發現未成年人向我們提供了個人資訊，請聯絡我們刪除。


十、政策變更

若本政策發生實質性變更，我們會在新版本的說明中更新，並修改頂部的生效日期。繼續
使用即表示你接受更新後的政策。


十一、聯絡我們

如對本政策有任何疑問、請求查閱或刪除你的個人資訊，請聯絡：
codelint@foxmail.com
