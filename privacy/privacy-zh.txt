码灵（Codelint）隐私政策

生效日期：2026-10-20


一、概述

码灵（Codelint）是一款运行在 iPhone 与 iPad 上的 AI 编程助手客户端。它的定位是
「工具」：由你提供模型服务地址、工作区文件与目标主机，码灵在你指定的范围内代为
执行操作。

码灵提供两种使用方式：

1. 自行配置模型服务：你填写自己的大模型 API 地址与密钥，对话直接由你的设备发送到
   该地址，不经过我们；
2. 使用内置模型：登录账号后，你可以使用我们提供的内置模型额度，此时对话内容会经
   我们的服务器转发给模型服务商。

为提供账号、订阅额度与内置模型，码灵设有一套由开发者运营的服务器（
https://ios.codelint.com）。除下文明确列出的内容外，我们不会收集、储存或上传你的
文件、代码与对话正文。


二、我们收集的信息

1. 账号信息（登录时收集）

   登录是可选的：不登录也可以使用自行配置模型的全部能力。

   - Apple 登录：我们会收到 Apple 提供的用户标识（sub）。若你授权，还会收到你的
     邮箱（可能是 Apple 的私密转发地址）与姓名。
   - 邮箱验证码登录：我们会收到你填写的邮箱地址，并向该邮箱发送一次性验证码。

2. 登录凭证与登录设备

   - 登录成功后，服务器签发访问凭证（secret），仅保存在你设备的安全存储（Keychain）
     中。
   - 为展示与管理登录设备，服务器会记录客户端生成的设备标识（duid）、最近一次登录
     时间与来源 IP 地址。

3. 订阅与购买

   订阅通过 Apple App Store 内购完成。我们不会接触你的支付方式、卡号或账单地址；
   仅从 Apple 收到交易凭证，用于校验订阅档位与到期时间，并在服务器记录你的档位与
   额度。

4. 内置模型调用（登录并使用内置额度时）

   当你使用内置模型时，对话内容、工具调用参数与工具结果会经我们的服务器转发给模型
   服务商。服务器只统计用量信息并用于额度扣减，包括：模型名称、上游域名、请求 ID、
   请求字节数、token 用量、响应状态与耗时。

   服务器不保存对话正文、代码内容与工具结果正文。

5. 意见反馈（你主动提交时）

   当你在 App 内提交反馈时，会上传：标题、正文、你选择填写的联系方式，以及客户端
   环境信息（应用版本与构建号、系统版本、机型、语言与地区、时区、可用存储空间、
   当前角色名）。环境信息用于定位问题，不含你的工作区内容与对话内容。

6. 用量与额度

   服务器按账号记录内置模型的调用次数与 token 用量，用于额度结算与展示。

7. 我们不做的事

   - 不使用广告标识符（IDFA），不做跨 App 追踪
   - 不接入第三方广告或第三方统计分析 SDK
   - 不收集通讯录、通话记录、短信
   - 不在后台持续获取你的位置
   - 不出售、出租你的个人信息


三、你自行配置的服务

以下数据的去向完全由你决定，我们不参与也不留存：

1. 模型服务
   你在设置中填写的大模型 API 地址与密钥。当你发起对话或调用工具时，对话内容、代码
   片段与工具输出会发送到你指定的地址，其处理方式取决于该服务商的政策。
   为便于模型服务商排查调用问题，请求头会附带应用名称与版本号、系统版本、设备型号
   与系统区域设置（User-Agent），不含账号、IP、设备唯一标识或对话内容。

2. SSH 主机
   你添加的远程主机地址、端口、用户名与密钥，仅用于连接你自己的主机，保存在本机。

3. MCP 服务
   你添加的 MCP 服务端点，请求仅发往你配置的地址（可为局域网或远程地址）。

4. 可选的本地代理组件
   项目源码中附带一个可自行部署的接口代理组件，用于转发与统计模型调用。若你自行
   部署并将模型请求指向它，流量将经过你自己的服务器；我们不提供该组件的托管服务。


四、本机存储的数据

以下内容保存在你的设备本地（SwiftData 与 App 沙盒内）：

- 工作区文件与目录，以及文件修改历史
- 会话与对话记录、技能与提示词
- 模型服务地址与密钥、SSH 主机配置、MCP 服务配置
- 登录凭证（仅 Keychain）
- 应用运行日志与事件记录（仅用于本机问题排查）

清除方式：在 App 内删除对应条目即可移除；卸载 App 会一并清除全部本地数据。


五、设备权限及用途

码灵仅在下列用途申请系统权限，且均可在系统设置中拒绝：

- 本地网络：连接同一局域网内的 MCP 服务
- 相册（仅写入）：把工作区中的图片保存到你的相册
- 音乐资料库：搜索并播放你「音乐」App 中的歌曲
- 麦克风与语音识别：把你说的话转成文字填进输入框
- 定位（使用时）：仅在你主动询问需要位置上下文的问题（例如「我附近的网络环境」
  「当前位置」「附近的咖啡馆」等）时，才会临时获取你的大致位置，作为发送给 AI 的
  对话上下文，并用于显示当前连接的 Wi-Fi 名称；不会在后台持续追踪位置
- 通知：在本地提醒任务执行结果（不经过任何服务器推送）
- 剪贴板：仅当你主动点击界面中的「复制」按钮时才会写入系统剪贴板；本 App 不提供
  AI 自动读取剪贴板的工具，不会未经你确认就读取剪贴板内容

拒绝某项权限只会影响对应功能，不影响其余功能的使用。


六、数据共享与第三方

我们只在必要时与下列第三方共享数据：

- Apple：Apple 登录（验证身份）、App 内购买（校验订阅），受 Apple 隐私政策约束
- 模型服务商：仅在你使用内置模型时，由我们的服务器转发你的请求内容
- 邮件服务商：向你的邮箱发送登录验证码与反馈回执

除上述情形及法律要求外，我们不会向第三方提供你的数据。


七、数据保留与删除

- 本机数据：你随时可在 App 内删除会话、文件或配置；卸载 App 即删除全部本地数据。
- 账号数据（邮箱、Apple 用户标识、订阅档位、额度与用量、登录设备记录）：在账号存续
  期间保留。你可发送邮件至 codelint@foxmail.com 申请删除账号，我们将在 15 个工作日
  内删除或匿名化处理，法律法规要求保留的除外。
- 服务器不保存对话正文，因此不存在需要单独删除的对话内容副本。


八、数据安全

- 客户端与服务器之间的通信使用 HTTPS（TLS）加密；
- 登录凭证保存在系统 Keychain，模型密钥与 SSH 密钥按你的选择保存在 Keychain 或本机
  沙盒；
- 服务器对账号数据按最小必要原则存储，访问受权限控制。


九、儿童隐私

码灵面向具备编程能力的开发者，不面向 16 岁以下未成年人，也不会在知情的情况下收集
未成年人的个人信息。若你发现未成年人向我们提供了个人信息，请联系我们删除。


十、政策变更

若本政策发生实质性变更，我们会在新版本的说明中更新，并修改顶部的生效日期。继续
使用即表示你接受更新后的政策。


十一、联系我们

如对本政策有任何疑问、请求查阅或删除你的个人信息，请联系：
codelint@foxmail.com
