码灵（Codelint）隐私政策

生效日期：2026-09-18


一、概述

码灵是一款运行在你的设备上的 AI 编程助手客户端。它的定位是"工具"：由你提供
模型服务地址、工作区文件和目标主机，码灵在你指定的范围内代为执行操作。

码灵没有云端账号体系，不要求你注册或登录，也不维护属于开发者的用户数据库。


二、我们不收集的信息

- 不收集姓名、手机号、邮箱、通讯录、通话记录等个人身份信息
- 不要求注册账号，不使用广告标识符（IDFA）进行追踪
- 不向开发者运营的服务器上传你的文件内容、代码或对话记录
- 不投放广告，不接入第三方广告或数据统计 SDK


三、你主动提供、并由你决定去向的信息

码灵的核心能力依赖你自行配置的服务地址，数据去向完全由你决定：

1. 模型服务
   你在设置中填写的大模型 API 地址与密钥。当你发起对话或调用工具时，对话内容、
   代码片段与工具输出会发送到你指定的地址。这些数据的处理方式取决于该服务商的
   政策，请以你所选择服务商的隐私政策为准。

2. SSH 主机
   你添加的远程主机地址、端口、用户名与密钥，仅用于连接你自己的主机，保存在本机。

3. MCP 服务
   你添加的 MCP 服务端点，请求仅发往你配置的地址（可为局域网或远程地址）。

4. 可选的本地代理组件
   项目源码中附带一个可自行部署的接口代理组件，用于转发与统计模型调用。若你自行
   部署并将模型请求指向它，流量将经过你自己的服务器；我们不提供该组件的托管服务。


四、本机存储的数据

以下内容保存在你的设备本地（SwiftData 与 App 沙盒内）：

- 工作区文件与目录，以及文件修改历史
- 会话与对话记录、技能与提示词
- 模型服务地址与密钥、SSH 主机配置、MCP 服务配置
- 应用运行日志与事件记录（仅用于本机问题排查）

清除方式：在 App 内删除对应条目即可移除；卸载 App 会一并清除全部本地数据。


五、设备权限及用途

码灵仅在下列用途申请系统权限，且均可在系统设置中拒绝：

- 本地网络：连接同一局域网内的 MCP 服务
- 相册（仅写入）：把工作区中的图片保存到你的相册
- 音乐资料库：搜索并播放你"音乐"App 中的歌曲
- 定位（使用时）：获取当前位置，用于显示当前连接的 Wi-Fi 名称
- 通知：在本地提醒任务执行结果（不经过任何服务器推送）
- 剪贴板：仅当你主动执行复制或粘贴类操作时才会读写系统剪贴板

拒绝某项权限只会影响对应功能，不影响其余功能的使用。


六、数据保留与删除

我们不保留你的数据副本。所有数据留存在你的设备以及你自行选择的服务端。
你随时可在 App 内删除会话、文件或配置；卸载 App 即删除全部本地数据。


七、儿童隐私

码灵面向开发者，不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。


八、政策变更

若本政策发生实质性变更，我们会在新版本的说明中更新，并修改顶部的生效日期。


九、联系我们
